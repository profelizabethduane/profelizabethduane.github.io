Conceitos Básicos

Antes de programar: entenda os termos

Para começar a trabalhar com a linguagem C, é importante conhecer alguns conceitos fundamentais sobre programação e o processo de criação de programas.

  • Código de Programa: texto escrito com os comandos de uma determinada linguagem de programação.
  • Programa: arquivo binário (executável) que executa os comandos do código de programa em linguagem de máquina.
  • Linguagem C: linguagem de alto nível para criação de código de programas. Os arquivos do código em C devem ser salvos com o tipo .c.
  • Compilação: processo em que se verificam erros de escrita no código. Se tudo estiver correto, é gerado um arquivo objeto (.o) do programa para a fase de linkedição.
  • Linkedição: junção dos arquivos objetos e das bibliotecas utilizadas no código para geração final do programa executável.

O fluxo completo desde o código até o programa executável:

código (.c) → compilação → (.o) → linkedição → programa executável (.exe)

Para auxiliar nesse processo, utilizamos programas de edição e compilação. Para programação em C temos várias opções: DevC++, CodeBlocks, Eclipse, Netbeans, Visual Studio. Neste curso utilizaremos o Dev-C++.

Todo programa em C segue o mesmo esqueleto. Antes de escrever qualquer cálculo, você precisa conhecer cada parte desse esqueleto e o que ela faz.

    // Bloco de comandos

#include <stdio.h> Importa a biblioteca📦 Biblioteca: conjunto de funções prontas que você pode usar no seu programa. A stdio.h (Standard Input/Output) fornece funções de entrada e saída como printf e scanf. de entrada e saída. Sem ela, printf e scanf não funcionam. Sempre na primeira linha.
int main() { } Função principal — ponto de partida de todo programa C. A execução começa aqui.

Conceito 2

Variáveis: guardando valores na memória

Uma variável é um espaço reservado na memória RAM com um nome e um tipo. Em C, toda variável precisa ser declarada antes de ser usada.

O que é declarar uma variável?

Declarar é informar ao compilador: "reserve um espaço na memória com este nome e este tipo". O compilador então sabe quanto espaço alocar e como interpretar os dados armazenados.

Os dois tipos desta aula

🔢
int

Número inteiro

Armazena números sem casas decimais. Ocupa 4 bytes (32 bits) na memória.

int nota1;
int nota2;
int nota1, nota2; // ou assim

Exemplos de valores: 0  7  -3  100

📐
float

Número decimal

Armazena números com casas decimais. Ocupa 4 bytes com precisão simples🔢 Precisão simples (single precision): formato de 32 bits (4 bytes) para representar números decimais. Permite cerca de 7 dígitos significativos. Ex.: 3.1415927. Para maior precisão use double (64 bits) — veremos em aulas futuras..

float tempC;
float tempK;
float tempC, tempK; // ou assim

Exemplos de valores: 3.14  273.15  -0.5

⚠️
Separador decimal em C é o ponto, nunca a vírgula. Escreva 273.15 — não 273,15. A vírgula tem outro significado na linguagem.

Regras para nomear variáveis

✅ Permitido
// letras, números e _
nota1
temp_celsius
mediaFinal
n
❌ Proibido
// inválidos:
1nota      // começa com número
nota final // espaço no nome
média      // acento
float      // palavra reservada
💡
Boas práticas: use nomes descritivos (tempCelsius em vez de x) e declare todas as variáveis no início de main(), antes dos comandos.

Conceito 3

Escrita e leitura: printf e scanf

Com variáveis declaradas, você precisa de dois comandos essenciais: um para mostrar valores na tela e outro para ler o que o usuário digita.

printf — exibir na tela

Imprime texto e/ou valores de variáveis no console. Os especificadores de formato (%d, %f…) são "buracos" onde os valores das variáveis são inseridos.

printf — exemplos
// Só texto:
printf("Ola, Mundo!\n");

// Texto + variável inteira:
int nota = 8;
printf("Nota: %d\n", nota);

// Texto + variável decimal:
float media = 7.5;
printf("Media: %.2f\n", media);  // .2 = 2 casas decimais

// Duas variáveis na mesma linha:
printf("Nota: %d  Media: %.1f\n", nota, media);

scanf — ler do teclado

Aguarda o usuário digitar um valor e o armazena em uma variável. Atenção: o nome da variável deve ser precedido por & (endereço de memória).

scanf — exemplos
int nota;
float tempC;

// Ler um inteiro:
printf("Digite a nota: ");
scanf("%d", &nota);

// Ler um decimal:
printf("Digite a temperatura em Celsius: ");
scanf("%f", &tempC);
🚨
Erro comum: esquecer o & no scanf. Sem ele, o programa compila mas pode travar ou gerar valores incorretos. O & diz ao scanf onde na memória guardar o valor digitado.

Especificadores de formato

Usados tanto no printf quanto no scanf para indicar o tipo do dado:

EspecificadorTipoExemplo de usoStatus
%d Inteiro (int) printf("%d", nota); Esta aula
%i Inteiro (int) — alternativo ao %d printf("%i", nota); Esta aula
%f Decimal (float) printf("%.2f", media); Esta aula
%s Texto (char[]) printf("%s", nome); Próximas aulas
%c Caractere único (char) printf("%c", letra); Próximas aulas
💡
Formatando casas decimais: use %.2f para exibir 2 casas decimais, %.4f para 4 casas, e assim por diante. Sem o ponto, o printf exibe 6 casas por padrão.
📊

Programa completo — exemplo_media.c

Observe como as três etapas (Entrada → Processamento → Saída) aparecem organizadas no código:

exemplo_media.c
#include <stdio.h>

int main() {

    // ── Declaração de variáveis ──────────────────
    int   nota1, nota2;
    float media;

    // ── ENTRADA ──────────────────────────────────
    printf("Digite a nota 1: ");
    scanf("%d", &nota1);

    printf("Digite a nota 2: ");
    scanf("%d", &nota2);

    // ── PROCESSAMENTO ────────────────────────────
    media = (nota1 + nota2) / 2.0;

    // ── SAÍDA ────────────────────────────────────
    printf("Media final: %.2f\n", media);

    return 0;
}
⚗️
Por que dividir por 2.0 e não por 2? Em C, a divisão entre dois inteiros resulta em inteiro: 7 / 2 = 3, não 3.5. Usar 2.0 força a divisão em ponto flutuante, preservando as casas decimais.
🔄
Padrão E·P·S: declare variáveis → leia com scanf (Entrada) → calcule (Processamento) → exiba com printf (Saída).

Problema: Calcular a área de um retângulo

Contexto: leia a base e a altura de um retângulo (valores decimais) e calcule a área (base × altura). Organize as linhas de código na ordem correta.

Programa completo — copie no Dev-C++

area_retangulo.c
#include <stdio.h>

int main() {

    float base, altura, area;

    printf("Digite a base (m): ");
    scanf("%f", &base);

    printf("Digite a altura (m): ");

    area = base * altura;

    printf("Area = %.2f m2\n", area);
