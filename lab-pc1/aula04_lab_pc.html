Revisão — Conceitos Anteriores

Tipos de variáveis em C

Na aula anterior você conheceu int e float. Nesta aula completamos o conjunto com double e char, e revisamos as regras de identificadores e as funções printf / scanf.

🔢
int

Número inteiro

Sem casas decimais. Ocupa 4 bytes.

int tempo_reacao;
int massa_molar = 46;

Especificador: %d

📐
float

Decimal — precisão simples

~7 dígitos significativos. Ocupa 4 bytes.

float temperatura;
float densidade = 0.789;

Especificador: %f

🔬
double

Decimal — precisão dupla

~15 dígitos significativos. Ocupa 8 bytes. Ideal para cálculos científicos de alta precisão.

double pressao;
double p = 2.300000;

Especificador: %lf

🔤
char

Caractere único

Um único símbolo entre aspas simples. Ocupa 1 byte. Vetores de char armazenam texto.

char tipo_reator = 'B';
char nome[50];

Especificadores: %c (char) · %s (string)

⚠️
float vs. double: na Engenharia Química, prefira double para cálculos que envolvem muitas casas decimais (termodinâmica, equações de estado). Use float quando o espaço de memória for crítico ou a precisão não for tão importante.

Identificadores — revisão das regras

Lembre-se: o nome de uma variável em C deve seguir estas regras:

✅ Válidos

❌ Inválidos

Especificadores de formato — tabela completa desta aula

EspecificadorTipoExemplo
%dInteiro (int)printf("%d", nota);
%fDecimal (float)printf("%.2f", media);
%lfPrecisão dupla (double)scanf("%lf", &pressao);

💡
Lendo double com scanf: use %lf (com o "l" de long). Para exibir com printf, %f funciona para os dois — mas é boa prática usar %lf de forma consistente com o tipo da variável.
💡
Lendo char com scanf: coloque um espaço antes do %c para descartar o Enter que ficou no buffer do teclado: scanf(" %c", &tipo_reator);. Sem o espaço, o caractere pode ser lido incorretamente após outra leitura.

📋 Exemplo 1 — Relatório de Processo Químico

Programa que declara, inicializa e imprime variáveis de diferentes tipos, simulando dados de um processo químico.

//exemplo1.c
/*
  Autor : coloque o seu Nome
  Data  : coloque a data
  Desc  : Declaração de variáveis e função printf
*/
#include <stdio.h>

int main() {

    // Declaração de variáveis para processo químico
    int    tempo_reacao;    // tempo em minutos
    float  temperatura;    // temperatura em °C
    double pressao;        // pressão em atm (alta precisão)
    char   tipo_reator;    // 'B'atelada, 'C'ontínuo, 'S'emibatelada

    // Atribuição de valores (condições do processo)
    tempo_reacao = 120;       // 2 horas
    temperatura  = 85.5;     // °C
    pressao      = 2.3;      // atm
    tipo_reator  = 'B';      // Batelada

    // Declaração com inicialização (propriedades da substância)
    float densidade  = 0.789; // g/cm³ (etanol)
    int   massa_molar = 46;  // g/mol (etanol)

    // Impressão dos dados do processo
    printf("=== RELATÓRIO DO PROCESSO QUÍMICO ===\n");
    printf("Condições Operacionais:\n");
    printf("- Tempo de reação: %d minutos\n", tempo_reacao);
    printf("- Temperatura: %.1f °C\n", temperatura);
    printf("- Pressão: %.1f atm\n", pressao);
    printf("- Tipo de reator: %c (Batelada)\n", tipo_reator);
    printf("\nPropriedades da Substância (Etanol):\n");
    printf("- Densidade: %.3f g/cm³\n", densidade);
    printf("- Massa molar: %d g/mol\n", massa_molar);

    return 0;
}

📋 Exemplo 2 — Leitura de Nome e Idade

Programa que utiliza scanf para ler dados do usuário e printf com \t (tabulação) para formatar a saída.

//exemplo2.c
/*
  Autor : <coloque o seu Nome>
  Data  : <coloque a data>
  Desc  : Utilização das funções printf e scanf
*/
#include <stdio.h>

int main() {

    char nome[50];        // Declara uma string (vetor de caracteres) para armazenar o nome do usuário
    int  idade;              // Declara uma variável inteira para armazenar a idade

    printf("Digite seu nome: ");  // Exibe uma mensagem solicitando o nome
    scanf("%s", nome);         // Lê um conjunto de caracteres

    printf("Digite sua idade: "); // Exibe uma mensagem solicitando a idade
    scanf("%d", &idade);      // Lê um valor inteiro

    // espaçamento horizontal com "\t"
    printf("Nome: %s \t\t\t Idade: %d\n", nome, idade);

    return 0;
}
💡
Atenção ao &: note que scanf("%s", nome) não usa & — porque nome já é o endereço do vetor. Para variáveis simples (int, float, char) o & é obrigatório.

Conceito Principal

Operadores Aritméticos

A linguagem C possui cinco operadores aritméticos básicos. Entender como cada um funciona — especialmente a divisão inteira e o operador de resto — é fundamental para escrever cálculos corretos.

OperadorFunçãoExemplo (a=10, b=3)Resultado
+Adiçãoa + b13
-Subtraçãoa - b7
*Multiplicaçãoa * b30
/Divisãoa / b3 (inteiros!) · 3.33… (floats)
%Resto da divisão (módulo)a % b1

⚠️ Divisão inteira vs. divisão em ponto flutuante

Esta é a armadilha mais comum para iniciantes em C. O comportamento do operador / depende do tipo dos operandos:

//divisão — comparação de tipos
int a = 7, b = 2;
float x = 7.0, y = 2.0;

// int ÷ int → int (trunca!)
printf("%d\n", a / b);    // → 3

// float ÷ float → float
printf("%.2f\n", x / y); // → 3.50

// int ÷ float → float
printf("%.2f\n", a / y); // → 3.50

// forçar float com sufixo:
printf("%.2f\n", a / 2.0); // → 3.50
int / int → int Ambos inteiros? O resultado é inteiro. A parte decimal é simplesmente descartada (truncada, não arredondada). 7 / 2 = 3, não 3.5.
float / float → float Se pelo menos um dos operandos for float ou double, o resultado preserva as casas decimais.
Forçar divisão decimal Use 2.0 em vez de 2, ou faça um cast🔄 Cast: conversão explícita de tipo. Exemplo: (float)a / b converte a para float antes de dividir, garantindo resultado decimal.: (float)a / b.
Regra geral Se qualquer operando for float ou double, a operação toda é promovida para esse tipo.

Operador % — Resto da Divisão (Módulo)

O operador % retorna o resto da divisão inteira. Só funciona com operandos inteiros (int). Muito útil para verificar se um número é par/ímpar, fazer conversões de unidades, etc.

//operador % — exemplos
printf("10 %% 3 = %d\n", 10 % 3);  // → 1  (10 = 3×3 + 1)
printf("15 %% 4 = %d\n", 15 % 4);  // → 3  (15 = 4×3 + 3)
printf("8  %% 2 = %d\n", 8  % 2);  // → 0  (divisão exata)

// verificar se número é par: se resto for 0, é par
int n = 7;
printf("%d %% 2 = %d\n", n, n % 2);  // → 1 (ímpar)

// Para imprimir o símbolo % no printf, use %%
printf("Rendimento: 95%%\n");         // → Rendimento: 95%
⚠️
Para imprimir o símbolo % dentro de um printf, escreva %%. Um único % seria interpretado como início de um especificador de formato e causaria comportamento indefinido.

Conceito 2

Precedência e Parênteses

Quando há múltiplos operadores em uma expressão, C segue uma ordem definida — chamada de precedência. Conhecê-la evita resultados inesperados em seus cálculos.

1º
( )
Parênteses — maior precedência. Sempre avaliados primeiro. Use-os sempre que quiser garantir a ordem.
2º
* / %
Multiplicação, divisão e módulo — avaliados antes de + e -. Da esquerda para a direita quando há empate.
3º
+ -
Adição e subtração — menor precedência. Avaliados por último. Da esquerda para a direita quando há empate.

📋 Exemplo 4 — Precedência de Operadores

Programa que demonstra a precedência de operadores aritméticos em C. Observe como a ausência de parênteses pode levar a resultados inesperados.

//exemplo4.c
/*
  Autor :
  Data  :
  Desc  : Precedência de Operadores
*/
#include <stdio.h>

int main() {

    // Sem parênteses: * antes de +
    int r1 = 2 + 3 * 4;        // → 14  (não 20!)
    //              └── 3*4=12 primeiro, depois 2+12
    printf("2 + 3 * 4 = %d\n", r1);

    // Com parênteses: força a soma primeiro
    int r2 = (2 + 3) * 4;       // → 20
    printf("(2 + 3) * 4 = %d\n", r2);

    // Média correta de dois inteiros:
    int n1 = 8, n2 = 6;
    float m;

    m = n1 + n2 / 2.0;         // ❌ → 11.0 (divide n2 antes de somar)
    printf("8 + 6 / 2.0 = %.1f (incorreto)\n", m);

    m = (n1 + n2) / 2.0;       // ✅ → 7.0  (soma antes de dividir)
    printf("(8 + 6) / 2.0 = %.1f (correto)\n", m);

    return 0;
}
💡
Dica de ouro: quando estiver em dúvida sobre a precedência, use parênteses. Eles tornam o código mais legível e eliminam ambiguidades.
(n1 + n2) / 2.0 é mais claro que depender da precedência.

Ordenar: Cálculo do IMC

Contexto: organize as linhas para um programa que lê nome, peso e altura, calcula o IMC e exibe o resultado.

Linhas embaralhadas — arraste para a ordem correta:

Programa completo — copie no Dev-C++

//imc.c
#include <stdio.h>

int main() {

    char  nome[50];
    float peso, altura, imc;

    printf("Digite seu nome: ");
    scanf("%s", nome);

    printf("Digite seu peso em kg: ");
    scanf("%f", &peso);

    printf("Digite sua altura em metros: ");
    scanf("%f", &altura);

    imc = peso / (altura * altura);

    printf("%s, seu IMC e: %.2f\n", nome, imc);

    return 0;
}
⚗️
Por que (altura * altura) e não altura^2? Em C não existe operador de potência. Para elevar ao quadrado, multiplique a variável por ela mesma. Para potências maiores, use a função pow(base, expoente) da biblioteca math.h.

Ordenar: Conversor Celsius → Fahrenheit

Contexto: organize as linhas para converter temperatura de Celsius para Fahrenheit. Fórmula: F = (C × 9/5) + 32.

Linhas embaralhadas — arraste para a ordem correta:

Programa completo — copie no Dev-C++

//celsius_fahrenheit.c
#include <stdio.h>

int main() {

    float celsius, fahrenheit;

    printf("Digite a temperatura em Celsius: ");
    scanf("%f", &celsius);

    fahrenheit = (celsius * 9.0 / 5.0) + 32.0;

    printf("%.2f C = %.2f F\n", celsius, fahrenheit);

    return 0;
}
💡
Por que 9.0 / 5.0 e não 9 / 5? Com 9 / 5 a divisão seria inteira: resultado 1 (não 1.8). A fórmula ficaria errada. Use 9.0 ou 9.0f para garantir divisão de ponto flutuante.

Resumo

O que você aprendeu hoje

🔢 int

Inteiros. 4 bytes. Especificador %d. Divisão entre ints trunca o resultado.

📐 float / double

Decimais. float = 4 bytes / 7 dígitos. double = 8 bytes / 15 dígitos. Use %lf no scanf de double.

🔤 char / char[]

Um caractere (1 byte, %c) ou vetor de caracteres para strings (%s). Use espaço antes de %c no scanf.

➗ Divisão inteira

int ÷ int = int (parte decimal truncada). Para obter decimal, use pelo menos um operando float ou adicione .0.

% Módulo

Retorna o resto da divisão inteira. Apenas para int. Para exibir o símbolo % no printf, use %%.

🔢 Precedência

Ordem: parênteses → * / % → + -. Em dúvida, use parênteses. (a+b)/2.0 ≠ a+b/2.0.
