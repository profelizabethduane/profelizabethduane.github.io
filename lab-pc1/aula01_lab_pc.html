// unidade 1.1 — hardware

Hardware: a parte física

Hardware são todos os componentes físicos do computador — o que você pode tocar. Antes de programar, é fundamental entender onde o programa vai rodar.

🧠

CPU — Unidade Central de Processamento

É o "cérebro" do computador. Executa todas as instruções: somar números, comparar valores, tomar decisões. Sua velocidade é medida em GHz (bilhões de operações por segundo).

Intel Core / AMD Ryzen 2 a 64+ núcleos 2–6 GHz
Analogia: A CPU é como o seu cérebro resolvendo uma prova. Você lê a questão (entrada), pensa e calcula (processamento) e escreve a resposta (saída). O que define sua "velocidade" é quantas questões consegue resolver por minuto — assim como a CPU é medida em operações por segundo.
⚡

Memória RAM — Memória de Trabalho

Guarda temporariamente os dados e programas que estão em uso agora. É muito rápida, mas volátil: ao desligar o computador, tudo que está na RAM é apagado.

DDR4 / DDR5 8 a 128 GB típicos Volátil
Analogia: A RAM é como a mesa onde você estuda. Você coloca ali só o que está usando agora — caderno, calculadora, caneta. Quando você termina e se levanta, a mesa fica vazia. Quanto maior a mesa, mais você consegue trabalhar ao mesmo tempo sem precisar ficar guardando e pegando coisas.
💾

Armazenamento — HD / SSD

Guarda dados permanentemente, mesmo com o computador desligado: arquivos, programas, sistema operacional. SSDs são muito mais rápidos que HDs mecânicos. É aqui que seu código em C fica salvo.

HDD (mecânico) SSD (memória flash) 256 GB a vários TB
Analogia: O armazenamento é como uma mochila ou estante de livros. Tudo que você guarda lá fica permanentemente — mesmo depois de ir embora. A diferença para a RAM (sua mesa de estudos): a estante guarda tudo para quando precisar depois; a mesa é só para o que está usando agora.
⌨️

Dispositivos de Entrada e Saída

Entrada: teclado, mouse, câmera, microfone — formas de fornecer dados ao computador.
Saída: monitor, caixa de som, impressora — formas do computador comunicar resultados ao usuário.

Entrada: teclado, mouse Saída: monitor, impressora
Analogia: Entrada é como fazer uma pergunta — você fornece informações. Saída é receber a resposta — o computador devolve o resultado. Em programação, o teclado é sua "voz" e o monitor é o "quadro" que mostra a resposta.
🎮

GPU — Processamento Gráfico e Paralelo

Originalmente para jogos, hoje usada em qualquer tarefa que precise de muitos cálculos simultâneos: inteligência artificial, simulações científicas e renderização 3D.

NVIDIA / AMD Milhares de núcleos IA / Simulações
Analogia: A GPU é como uma turma inteira resolvendo uma prova ao mesmo tempo. A CPU é um aluno muito inteligente que resolve questões difíceis uma de cada vez. A GPU são 5.000 alunos, cada um resolvendo uma questão simples simultaneamente — no total, muito mais rápido para certas tarefas.
// unidade 1.2 — software

Software: as instruções

Software é o conjunto de instruções que diz ao hardware o que fazer. Sem software, um computador é apenas um conjunto de peças físicas — não faz nada útil por conta própria.

// tipo 1

🖥️ Sistema Operacional

Gerencia todos os recursos do computador. Faz a ponte entre você e o hardware.

Exemplos: Windows, Linux, macOS

// tipo 2

🛠️ Software Aplicativo

Programas criados para tarefas específicas do usuário.

Exemplos: Word, Excel, MATLAB, calculadora

// tipo 3

✍️ Linguagem de Programação

Ferramenta para escrever novos softwares e dar instruções ao computador.

Nesta disciplina: linguagem C
Outros Exemplos: C++, Python, Java

Cada linguagem tem sintaxe própria, mas todas se traduzem para instruções que a CPU entende.

// de texto para máquina

Como seu código vira ação?

Você escreve código em linguagem C (legível por humanos), o compilador (outro software) traduz isso para linguagem de máquina (0s e 1s), e a CPU lê esses comandos e os executa.

💡 O compilador é um software que atua como tradutor: converte seu código (que você entende) para instruções binárias (que a CPU entende). Você aprenderá a usar o compilador GCC nas próximas aulas.

Dados: a matéria-prima

Computadores entendem apenas 0 e 1 — dois estados elétricos: desligado e ligado. Tudo que existe no computador (texto, números, imagens, vídeos) é representado por combinações desses dois valores.

💡 Por que 1.024 e não 1.000? Computadores trabalham em base 2 (binário): 2¹⁰ = 1.024. É a "centena" do mundo binário.

O papel do programa é transformar dados brutos em informação útil para tomada de decisão.

Programação não é exclusividade de quem vai trabalhar com TI. Engenheiros químicos modernos usam código para resolver em segundos o que levaria horas manualmente.

✍️ Atividade 3 — Reflexão escrita

Não existe resposta única certa. Escreva com suas palavras e compare com a sugestão.

1. Pense em algum cálculo repetitivo que você já fez (nota final, média, conversão de unidades). Se você fosse ensinar um robô a fazer esse cálculo, quais seriam os passos em ordem?

Exemplo — Calcular nota final desta disciplina:
1. Pedir a nota da Prova 1 (0 a 40)
2. Pedir a nota da Prova 2 (0 a 40)
3. Pedir a nota das listas (0 a 20)
4. Somar os três valores
5. Se a soma ≥ 60, mostrar "Aprovado"; caso contrário, "Recuperação"

Isso é exatamente o que você vai implementar em C nas próximas semanas!

2. Qual a diferença entre a memória RAM e o HD/SSD? Por que um computador precisa dos dois?

A RAM é rápida mas temporária — guarda o que está em uso agora. O HD/SSD é permanente mas mais lento — guarda tudo que precisa existir depois que o computador desliga.

Um computador precisa dos dois porque trabalhar só com HD seria lento demais (como escrever direto na estante, sem mesa), e trabalhar só com RAM significaria perder tudo ao desligar.
⚡ Desafio — Interprete o fluxograma

Analise o fluxograma abaixo e responda: o que o programa calcula e quais serão as saídas possíveis?

O que o programa faz: lê um número N, calcula seu quadrado (N²) e verifica se o resultado é maior que 100.

Se N = 8: 8 × 8 = 64 → 64 > 100? Não → exibe "Pequeno!"
Se N = 11: 11 × 11 = 121 → 121 > 100? Sim → exibe "Grande!"

Perceba a estrutura: Entrada → Processamento → Decisão → Saída — esse é o esqueleto de qualquer algoritmo.
