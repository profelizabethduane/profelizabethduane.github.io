Conceitos

Instrução, Algoritmo e Programa

Antes de escrever qualquer linha de código é preciso dominar três conceitos que formam a base da programação.

📌
Conceito 1

Instrução

Uma ação elementar — uma frase que indica exatamente o que deve ser feito.

Exemplos:
• Abra a porta
• Misture os reagentes
• Anote o valor medido

📋
Conceito 2

Algoritmo

Uma sequência lógica e finita de instruções que leva à execução de uma tarefa.

Todo algoritmo tem:
• Início e fim definidos
• Passos em ordem lógica
• Resultado esperado

💻
Conceito 3

Programa

Um algoritmo escrito em uma linguagem de programação que o computador consegue executar.

Exemplos de linguagens:
• C, C++, Python, Java
• Cada uma tem sua sintaxe📖 Sintaxe é o conjunto de regras que define como as instruções devem ser escritas em uma linguagem. Assim como o português tem gramática, a linguagem C tem sintaxe: cada palavra, símbolo e pontuação precisam estar no lugar certo para o compilador entender o código. própria

💡
A relação entre os três: você cria uma instrução para cada passo; a sequência de instruções forma um algoritmo; ao escrever esse algoritmo em C você tem um programa.

Linguagem de Programação

Do algoritmo ao programa

Um algoritmo escrito em português não é executável pelo computador. É necessário traduzi-lo para uma linguagem formal que a máquina compreenda.

O que é uma linguagem de programação?

É um conjunto de regras e símbolos — a sintaxe — que permite escrever algoritmos de forma que o computador possa interpretá-los e executá-los. Cada linguagem tem suas próprias palavras reservadas, operadores e estruturas.

Do código à execução: o papel do compilador

Você escreve código em linguagem C. Um programa chamado compilador traduz esse código para linguagem de máquina (0s e 1s). A CPU então executa essas instruções.

Linguagem natural × Linguagem formal

Linguagem Natural

Como humanos comunicam

Usada no cotidiano. É ambígua: a mesma frase pode ter interpretações diferentes dependendo do contexto.

"Adicione um pouco de sal"
→ Quanto é "um pouco"?

Linguagem Formal

Como máquinas entendem

Usada em programação. É precisa e sem ambiguidade: cada instrução tem um único significado.

sal = sal + 5;
→ Soma exatamente 5 unidades.

⚠️
Ponto importante: o computador executa exatamente o que você escreve — não o que você quis dizer. Por isso a precisão da linguagem formal é fundamental.

Exemplos de ambiguidade

Veja como a mesma ideia expressa em linguagem natural pode ter múltiplas interpretações — e como a linguagem formal elimina essa dúvida:

Instrução em linguagem natural Problema de ambiguidade Versão formal (precisa)
"Aqueça um pouco o reator" Quanto é "um pouco"? 5 °C? 20 °C? temperatura = temperatura + 10.0
"Some os números" Quais números? Quantos? Onde está o resultado? resultado = valor1 + valor2
"Mostre o resultado se for grande" O que é "grande"? Maior que 100? Maior que 1000? se (resultado > 100) escreva(resultado)
"Repita até acabar" Acabar o quê? Quando exatamente para? enquanto (contador < 10) { ... }
Tipos de Algoritmos

Três formas de representar um algoritmo

Um mesmo algoritmo pode ser representado de três formas. Cada uma tem vantagens em diferentes contextos.

🗣️ Descrição Narrativa

Passos em linguagem natural, numerados em ordem. Fácil de entender, mas pode ser ambígua.

Celsius → Kelvin:
Passo 1 — Leia a temperatura em °C
Passo 2 — Some 273,15 ao valor lido
Passo 3 — Mostre o resultado em Kelvin
🔷 Fluxograma

Representação visual com símbolos padronizados. Facilita a visualização do fluxo lógico.

tempK = tempC + 273,15
↓
Mostre tempK
↓

📝 Pseudocódigo (Portugol)

Mistura linguagem natural com estrutura de programação. Ponte entre algoritmo e código real.

real tempC, tempK

escreva("Temperatura em °C: ")
leia(tempC)

tempK = tempC + 273.15

escreva("Kelvin: ", tempK)

Principais símbolos do fluxograma

início / fim

Oval — início e fim

entrada / saída

Paralelogramo — leitura ou exibição

processamento

Retângulo — cálculo ou atribuição

decisão

Losango — condição

🌡️ Tarefa: Converter Celsius para Kelvin

Objetivo: escrever, executar e testar um algoritmo em Portugol que leia uma temperatura em graus Celsius e mostre o equivalente em Kelvin.

Análise do problema — Celsius para Kelvin

Antes de escrever o algoritmo, identifique: entrada, processamento e saída.

EtapaDescriçãoVariável / Fórmula
EntradaTemperatura fornecida pelo usuáriotempC (número real)
ProcessamentoAplicar a fórmula de conversãotempK = tempC + 273,15
SaídaTemperatura em Kelvin exibida na telatempK
⚗️
Por que Kelvin na Engenharia Química? A escala Kelvin é a escala absoluta de temperatura. Equações como a dos gases ideais (PV = nRT) exigem T em Kelvin. O zero absoluto (0 K = −273,15 °C) é o ponto de energia cinética mínima das moléculas.
  • 1
    Acesse portugol.dev no navegador e clique em "Novo arquivo".
  • 2
    Apague o código de exemplo e digite o pseudocódigo abaixo:
programa {
  funcao inicio() {

    // Declaração das variáveis
    real tempC, tempK

    // Entrada de dados
    escreva("Digite a temperatura em Celsius: ")
    leia(tempC)

    // Processamento
    tempK = tempC + 273.15

    // Saída
    escreva("Temperatura em Kelvin: ", tempK, "\n")

  }
}
  • 3
    Clique no botão ▶ Executar e insira um valor quando solicitado.
  • 4
    Teste com os valores abaixo e verifique se os resultados estão corretos:
    Entrada (°C)Resultado esperado (K)
    0273,15 — ponto de fusão da água
    100373,15 — ponto de ebulição da água
    −273,150 — zero absoluto
    25298,15 — temperatura ambiente padrão
  • 5
    Execute e confira os resultados. Quando tiver o programa funcionando, passe para o desafio abaixo.
