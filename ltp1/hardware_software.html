Software: A Parte Lógica

Software são as instruções que dizem ao hardware o que fazer. Existem diferentes tipos, cada um com uma finalidade específica.

👑

Sistemas Operacionais

Gerenciam todo o computador. São os "maestros" que garantem que hardware e outros softwares trabalhem em harmonia. Exemplos: Windows, Linux, macOS.

🛠️

Softwares Aplicativos

Programas para tarefas específicas. Na Engenharia Química, usamos MATLAB, Python, Excel e simuladores como ASPEN HYSYS.

✍️

Linguagens de Programação

As ferramentas que usamos para criar novos softwares e dar instruções ao computador. Em breve, começaremos a usar Python!

Dados: A Matéria-Prima

Dados são fatos brutos. O computador os processa para gerar informação útil. Tudo em um computador é representado por 0s e 1s (bits).

De Bits a Informação

Computadores entendem apenas "ligado" (1) e "desligado" (0). Esses são os **bits**. Um conjunto de 8 bits forma um **byte**, que pode representar um caractere, como a letra 'A'.

O gráfico ao lado mostra como essas unidades crescem, permitindo armazenar dados cada vez mais complexos.
